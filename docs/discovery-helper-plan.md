# 발견 도우미 플랜: 새 모델·서비스·기능 소식을 찾아 추천만 하고, 승인 후에만 추가 (2026-10-23)

요청: JetAI가 가끔 인터넷을 보고 추가할 만한 기능이나 LLM을 알려 주고, LLM을 스스로 추가하는 기능도 있었으면 한다. 이 문서는 **계획**이며 구현은 아직 시작하지 않았다.

## 1. 원칙 (기존 규칙을 그대로 유지)
1. **추천만 한다. 설치·등록·결제는 사용자의 승인 뒤에만.** 모델 다운로드는 정확한 크기를 보여 주고 확인받는 기존 규칙(`engine.py`) 그대로.
2. **기본은 꺼짐(opt-in).** 켜면 수동 버튼 "지금 찾아보기"가 먼저, 주기 실행은 그다음 선택 사항.
3. **비용 0.** 유료 API를 쓰지 않는다. 요약·비교에는 이미 연결된 무료·로컬 모델만, 그것도 필요할 때만.
4. **인터넷 글은 데이터이지 지시가 아니다.** 읽어 온 글이 모델에게 들어가도 도구 권한·파일 접근·URL 생성 권한이 없고, 결과는 정해진 JSON 형식으로만 받는다.
5. **사실은 구조화된 값에서, 평가는 측정에서.** 크기·파라미터 수·라이선스·다운로드 수는 API가 준 값만 그대로 쓰고, "더 똑똑하다" 같은 성능 주장은 **JetAI가 측정하기 전까지 "측정되지 않음"으로 표시**한다.
6. 읽기 전용 외부 접근(익명 GET, 키·개인정보 전송 없음). 엔진·모델 실행·라우터는 건드리지 않는다.

## 2. 이미 있는 것(재사용, 중복 개발 금지)
| 기능 | 위치 | 이번에 쓰는 법 |
|---|---|---|
| 새 무료 서비스 하루 한 번 발견(규칙 기반, 주소 검증) | `servicefeed.py` | 출처 하나로 유지하고 "발견" 편지함에 카드로 통합 |
| 연결한 서비스의 새 모델 알림 | `modelwatch.py`, `modelinfo.py` | 같은 편지함에 "새 모델" 카드 |
| 이 PC에 맞는지 계산(가중치+KV 캐시+여유, GPU/부분/CPU/불가) | `engine.fit_with_context`, `engine.detect_hardware` | 후보가 **이 PC에서 돌아가는지**를 카드에 표시, 안 맞으면 숨김/회색 |
| 후보 모델 메타데이터(설치 불가 목록) | `engine.CANDIDATES`, `FACTS` | 발견한 모델이 여기와 겹치면 합침 |
| 크기 확인 후 다운로드·실행 | `engine.plan/install` | 카드의 "추가"가 이 흐름으로만 연결 |
| 무료 한도 보호(Mercury 3 등) | `quotaguard.py` | 새 서비스가 "보호 대상"이면 같은 보호 규칙 적용 |
| 하네스 측정 | `agenteval.py` | 후보 모델을 **내 PC에서 직접 측정**하는 버튼(후속) |

## 3. 설계
### 3.1 출처(허용 목록, 코드에 고정, 사용자가 추가하려면 승인)
| 출처 | 용도 | 접근 방식 |
|---|---|---|
| Hugging Face 모델 API(`huggingface.co/api/models`, GGUF 필터) | 이 PC에 맞는 새 GGUF 모델 후보 | 익명 GET, JSON |
| GitHub Releases API(llama.cpp, OpenCode, Ollama) | 새 기능·바뀐 점 소식, 엔진 업데이트 | 익명 GET, JSON |
| 기존 무료 서비스 목록(`servicefeed`) | 새 무료 서비스 | 기존 코드 그대로 |
| (선택·후순위) 웹 검색 | 허용 목록 밖의 소식 | **기본 제외**. 켜면 결과 글을 데이터로만 취급하고 카드에는 "미검증" 표시 |

받는 크기 상한, 시간 제한, 리다이렉트는 허용 도메인 안에서만, `ETag`/`If-None-Match`로 변경 없을 때 재다운로드 안 함.

### 3.2 처리 단계(LLM은 마지막에, 선택적으로)
1. **수집**: 허용된 API에서 JSON만 받는다.
2. **규칙 기반 가공**: 이름·파라미터 수·양자화·파일 크기·라이선스·다운로드 수·갱신일을 뽑고, 중복·이미 설치된 것·이 PC에 안 맞는 것을 제거한다(`fit_with_context`).
3. **(선택) 요약**: 릴리스 노트 같은 자유 글만 연결된 무료·로컬 모델로 2~3줄 요약. 입력은 길이 상한, 출력은 `{"summary": "...", "relevant": true/false}` 형식만 허용하고 형식이 틀리면 버린다. 요약은 "AI 요약(틀릴 수 있음)"으로 표시.
4. **카드 생성**: 출처 링크, 값(크기·라이선스 등), 이 PC 적합 여부, "측정되지 않음" 라벨을 붙여 편지함에 저장.

### 3.3 저장·중복·무시
`~/.agent-workshop/discovery.json`: 카드(종류·id·출처·값·상태)와 사용자가 "무시"한 id 목록. 같은 카드를 다시 만들지 않고, 처리한 카드는 일정 기간 후 정리(사용자 기록은 지우지 않음).

### 3.4 화면
- 설정 안의 **"발견" 탭**과 사이드바의 작은 점(읽지 않은 카드 수). 카드 종류: 모델 / 서비스 / 소식.
- 카드 버튼: **자세히**(출처 링크·값), **추가**(모델은 크기 확인 창 → 기존 내려받기, 서비스는 서비스 마법사로 미리 채워 이동, Ollama 모델은 `ollama pull` 명령을 **복사**만 하고 실행하지 않음), **무시**, **이 PC에서 측정**(후속).
- 상단 스위치: 켬/끔, "지금 찾아보기", 주기(끔/주 1회).

### 3.5 안전 점검표
- 읽은 글에 "이 파일을 받아라/이 명령을 실행해라" 같은 문장이 있어도 **카드의 동작 버튼은 코드가 만든 것만** 있다(글이 버튼·명령을 만들 수 없음).
- 모델 카드의 다운로드 주소는 **API가 준 레포 이름으로 코드가 조립**하고, 허용 도메인(`huggingface.co`)·확장자(`.gguf`)·크기·해시 확인을 기존 `engine`이 한다.
- 새 서비스 카드는 `servicefeed`의 기존 주소 검증(https, 사설 주소 금지 등)을 통과한 것만.
- 모든 외부 읽기는 감사 기록(`discovery.log`: 시각·출처·결과 개수, 글 내용 없음).

## 4. 단계와 완료 기준
| 단계 | 내용 | 완료 기준 |
|---|---|---|
| D0 | 카드 저장소·편지함 API·"발견" 탭(빈 상태), 켬/끔 | 껐을 때 외부 접근 0, 카드 추가·무시가 재실행 후에도 유지 |
| D1 ✅(2026-10-24) | Hugging Face 모델 후보(규칙 기반 가공 + 이 PC 적합성) | 가짜 API 응답 시험: 안 맞는/이미 있는 모델 제외, 크기·라이선스 표시, 성능 주장 없음 |
| D2 ✅(2026-10-24, Ollama 명령 복사는 아직) | 카드의 "추가" → 기존 크기 확인·내려받기 연결, Ollama는 명령 복사 | 확인 없이는 다운로드 시작 안 함(기존 테스트 유지) |
| D3 | GitHub 릴리스 소식 + (선택) 무료·로컬 모델 요약 | 요약 형식 위반·주입 문장 시험에서 카드에 동작이 생기지 않음 |
| D4 | 서비스 카드 통합(`servicefeed`), 주 1회 주기 실행(기본 꺼짐) | 한도·오류에서 조용히 실패, 재시도 폭주 없음 |
| D5(후속) | "이 PC에서 측정": 후보 모델을 하네스 쉬운·어려운 과제로 돌려 카드에 결과 첨부 | 측정 값이 있을 때만 "측정됨"으로 표시 |

테스트 원칙: 외부 호출은 전부 가짜 서버/가짜 응답으로(CI에서 인터넷 불필요). 실제 네트워크 확인은 사용자 PC에서 수동 1회로 따로 표시. 로컬에서는 관련 테스트만 돌린다.

## 5. 위험과 대응
| 위험 | 대응 |
|---|---|
| 읽은 글을 통한 지시 주입 | 글은 데이터로만, 출력 형식 고정, 동작 버튼은 코드 고정, 승인은 항상 사용자 |
| 잘못된·악성 모델 파일 | 다운로드는 기존 엔진 경로(허용 도메인·크기·해시), 새 형식 지원은 이번 범위 밖 |
| 광고성·과장된 성능 주장 | 성능 문구를 만들지 않음, 측정 전에는 "측정되지 않음" |
| 외부 API 제한·장애 | 캐시(ETag), 최소 간격, 실패 시 조용히 건너뛰고 마지막 카드 유지 |
| 개인정보 | 보내는 것은 익명 GET 요청뿐(쿼리에 사용자 정보 없음) |
| 범위 확장(웹 검색) | 후순위·기본 제외, 도입 시 별도 승인 |

## 6. 사용자가 정해 주면 좋은 것 (답이 없으면 괄호의 기본값)
1. 출처: Hugging Face + GitHub 릴리스 + 기존 무료 서비스 목록으로 시작(웹 검색은 제외).
2. 주기 실행: 처음에는 **수동 버튼만**(주 1회 자동은 D4에서 선택).
3. 요약에 LLM을 쓸지: **쓰지 않고 시작**(D3에서 선택 기능으로).
4. 모델 "추가"는 내장 엔진 경로만 자동 연결하고, Ollama는 명령 복사까지만.
