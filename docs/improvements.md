## 5. 모바일 원격 제어 (결정 필요)
| 방법 | 장단점 | 안전 |
|---|---|---|
| **텔레그램 봇**(권장) | PC가 바깥으로만 연결(포트를 열지 않음). 폰 앱 설치만 하면 됨. 명령: 질문·상태·승인·중단 | 내가 만든 봇 + **내 계정 ID만 허용**. 대화 내용이 텔레그램 서버를 지나감(경고 필요). 토큰은 저장소 밖 |
| 같은 와이파이/Tailscale로 웹 화면 접속 | 화면 그대로 쓸 수 있음 | 지금은 127.0.0.1만 열도록 막아 둠. 열려면 로그인·HTTPS·접속 허용 목록 설계가 먼저 |
| 디스코드 봇 | 텔레그램과 비슷 | 서버·역할 설정이 더 번거로움 |
| 카카오톡 | 일반 봇이 어려움(비즈니스 채널 필요) | 비추천 |
앱은 원본(대화·큐)을 PC에 두고, 폰은 보조 창구로만 씁니다. 알림은 중요도별로 묶어서 보냅니다.
