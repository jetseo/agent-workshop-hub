## 앞으로 할 일 (우선순위 순)
1. **PC 실사용 검증 (사용자와 함께)** 🟡→✅: `jetai.ps1` 실행, 실제 무료 서비스 1~2개 연결, 압축·보드·계정 전환 확인. 결과로 서비스 주소 오류와 Windows 전용 문제를 잡는다. *가장 먼저 필요한 일.*
2. **설치 패키지** ⬜: (a) 내장 파이썬을 넣은 압축 파일 ✅ GitHub 러너에서 빌드·압축 해제·실행 확인, PC 🟡 → (b) 설치 프로그램(시작 메뉴·제거). 관리자 권한·자동 다운로드·자동 업데이트 없음.
3. **첫 실행 온보딩 보강** 🟡: 건너뛰기, 연결 실패 원인별 안내는 구현함. 남은 것: 서비스별 무료 한도 안내 최신화, 설정 화면을 앱 안으로 통합.
4. **토큰 절약 확대** ⬜: 작업 전 비용 예측, 서비스별 일일 한도·경고, 긴 대화 자동 요약으로 컨텍스트 절약.
5. **안정성** ⬜: 앱 종료 시 서버 정리, 포트 충돌·중복 실행 처리, 로그 파일, 데이터 폴더 백업·내보내기.
6. **Windows 단독 터미널** ⬜(마지막): ConPTY 기반. WSL 없는 사용자용이며 우선순위 낮음.
7. **정리** 🟡: 설정(`/setup`)·작업·보드·사용량 화면의 디자인을 채팅 앱과 통일(✅, 라이트·다크). 영어 문구의 한글화(작업·보드·설정 화면, 연결·계정 오류 메시지)도 ✅. 설정 화면을 앱 안으로 통합(✅, 서비스 목록·모델 추가·계정 관리·연결 해제·이 PC 환경). 문서 통합(✅, README를 현재 기능에 맞게 다시 쓰고 `docs/README.md` 목차 추가).

## 사용자가 결정해야 하는 것
- 저장소 이름 변경(GitHub 설정에서 직접) — 변경하면 알려 주기.
- (결정됨) 이미지·ComfyUI 기능은 이 저장소에서 제거하고 `docs/handoff/jet-studio-comfyui-prompt.md`로 Jet Studio에 넘김. Jet Studio 세션에 그 문서를 붙여 넣는 일은 사용자가 함.
- 설치 프로그램 형태: 압축 파일만 / 설치 프로그램(.exe)까지.

## 하지 않는 것
자동 유료 호출, 키 덮어쓰기, 모델 자동 다운로드, 관리자 권한 자동 요청, 자동 병합, 계정 자동 생성·가입 우회, 외부 노출(항상 127.0.0.1만).
