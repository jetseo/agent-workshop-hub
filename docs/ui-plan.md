# UI 개선 플랜: 접히는 패널·크기 조절·생산성 기능 (2026-10-23)

계기: 코드 화면에서 가운데 "작업 목록" 칸이 좁아 제목·상태·시간이 줄바꿈되고(작업 하나가 4~5줄), 패널을 접거나 넓힐 수 없음. 목표는 ChatGPT·Claude 데스크톱 앱처럼 **패널을 접고 펴고, 폭을 끌어서 조절하고, 키보드로 빠르게 다니는** 화면. U1은 구현·머지됨(검증 수준은 `docs/verification.md`: 내장 브라우저 측정까지, 실제 마우스·터치·앱 창은 미확인). U2~U4는 아직 플랜이다.

## 1. 참고한 오픈소스·프로젝트 (찾은 것과 가져올 것)
JetAI는 **표준 라이브러리 + 한 개의 `app.js`**(의존성 0, 결정 D1)라서, 코드를 들여오지 않고 **동작 방식만 참고해 직접 구현**한다.

| 프로젝트 | 확인한 내용 | 가져올 점 |
|---|---|---|
| [Open WebUI](https://github.com/open-webui/open-webui), [LobeChat](https://github.com/lobehub/lobe-chat), [LibreChat](https://github.com/danny-avila/LibreChat), [Jan](https://github.com/janhq/jan), [Cherry Studio](https://github.com/CherryHQ/cherry-studio) | 비교 글에서 기능 목록만 확인(검색 결과에는 사이드바 동작 설명이 없었음). ## 2. 기능 목록 (우선순위순)
**A. 레이아웃 (가장 급함: 줄바꿈 문제의 직접 해결)**
1. 왼쪽 메뉴 접기/펴기: 버튼 + `Ctrl+B`. 접으면 **아이콘만 남는 얇은 레일**(≈56px)로, 펴면 지금 크기. 상태는 `localStorage`에 저장.
2. 가운데 "작업 목록" 접기: 코드 화면 머리글의 버튼 + `Ctrl+Shift+B`. 접으면 대화·타임라인이 넓어짐.
3. 패널 폭 끌어서 조절: 메뉴/작업 목록 경계에 손잡이. 최소·최대 폭, 더블클릭으로 기본값, 키보드(←→)로도 조절, 폭 저장.
4. 작업 목록 **한 줄 요약 행**: 제목 한 줄(말줄임 + 마우스를 올리면 전체), 상태 점·색(진행/검토/실패/버림), 시간은 오른쪽에 짧게(`오후 11:16`), 파일 수·+/−는 보조 줄 한 줄. 넓은 폭이면 2줄까지.
5. 좁은 창(<900px)에서는 패널을 자동으로 접고, 열면 위에 겹쳐 뜸(스크림). 이미 있는 모바일 사이드바 동작을 재사용.

**B. 이동·검색 (생산성)**
6. `Ctrl+K` 명령 팔레트: 화면 이동(채팅·코드·설정…), 최근 대화·작업 검색, "새 채팅/새 작업", 모델 바꾸기.
7. 작업·대화 목록 **검색 상자와 상태 필터**(진행 중/검토 대기/실패/버림). 버림·평가용 작업을 한 번에 숨기거나 **일괄 정리**("버림 모두 지우기", 확인 후).
8. 목록 **프로젝트별/날짜별 묶음**(접기 가능). 고정(핀), 이름 바꾸기, 오른쪽 클릭 메뉴.
9. 단축키 정리: `Ctrl+N` 새 채팅, `Ctrl+Shift+N` 새 작업, `Ctrl+Enter` 보내기(이미 있음), `Esc` 닫기, `?` 단축키 도움말.

**C. 코드 작업 화면 (Claude Code/Codex 방식)**
10. 오른쪽 **변경 사항 패널**(접히는 3번째 패널): 변경 파일 목록(+/− 수), 선택한 파일의 diff.
11. diff **줄 댓글** → 모아서 "이 의견대로 고쳐줘" 한 번에 재작업(새 복사본에서, 기존 정책 유지).
12. 타임라인 **단계 접기**: 도구 호출·로그는 기본 접힘, 실패 단계만 펼침. 각 단계 복사 버튼.
13. 머리글에 현재 프로젝트·모델·방식·시도 횟수 칩(바로 바꿀 수 있게).

**D. 채팅·기타**
14. 글자 크기(작게/보통/크게), 줄 간격, 테마(라이트/다크/시스템) — 지금은 라이트/다크 토글만 있음.
15. 메시지 편집 후 다시 보내기, 응답 복사(이미 있음)·마크다운 전체 복사.
16. 창 크기·위치 기억(앱 창 모드), 마지막으로 연 화면 복원.

## 4. 구현 원칙·위험
- **의존성 0 유지**: 새 라이브러리 없이 `app.js`/`app.css`. 지금 `app.js`가 한 파일로 크므로 U1에서 레이아웃 코드는 **별도 정적 파일(`layout.js`)**로 분리를 검토(서버가 `/static/`을 이미 제공).
- **접근성**: 손잡이는 `role="separator"`, `aria-orientation`, 키보드 조작. 접힌 레일 버튼에는 `aria-label`·툴팁.
- **저장**: 폭·접힘 상태는 `localStorage`(읽기 실패해도 기본값으로 동작, 예외 처리).
- **확인 방법**: `node --check`, 내장 브라우저로 폭별 스크린샷, 정적 HTML에 필요한 id가 있는지 확인하는 단위 테스트. 실제 앱 창(Edge `--app`)에서의 확인은 사용자 PC에서만 가능하므로 **검증 수준을 따로 표시**한다.
- **위험**: 포인터 이벤트 폭 조절은 터치/펜에서 다를 수 있음(U1에서 포인터 이벤트로 통일). 줄 댓글(C11)은 재작업 흐름을 건드리므로 U3에서 별도 PR로 작게 나눈다. 작은 PR 원칙: U1을 다시 둘로 나눌 수 있음(A1~A3 / A4~A5).
- **범위 밖**: Jet Studio(쇼츠) 관련 UI, 이미지·영상 기능.
