- **확인**: 단위 테스트 6개(기본 꺼짐·기억, 카드 검증, 중복·무시 유지, 안 읽음 수, 상한, 깨진 파일) + 정적 테스트, 내장 브라우저에서 가짜 카드 2장으로 목록·켜기·무시·출처 링크(`noopener`) 확인. **확인하지 않음**: 실제 앱 창, 밝은 테마, 카드가 수십 장일 때의 모양.

## 무료 한도 보호: 주소 기반 보호 (2026-10-24)
- 감사에서 찾은 결손: 보호 대상 주소(`GUARDS[...]["hosts"]`)가 코드에 있었지만 쓰이지 않아, **`guard` 필드 없이 등록하면 Mercury 3 호출이 보호를 건너뛸 수 있었다.** 주소(정확히 일치)로도 보호를 찾도록 수정(`quotaguard.guard_for_url`, `guard_id`, `providers.load`). 전체 감사 표는 `docs/architecture/free-quota-guard.md`.
- **확인**: `GuardByHostTests` 4개 + 기존 보호 테스트 전부(31개), 영향 범위 테스트 129개(채팅 API·코드 작업·설정·라우터) 통과. 실제 Mercury 키로 호출한 적은 없고, 모든 시험은 가짜 서버·네트워크 차단 가짜 함수로 했다.

## 서비스 응답 확인 날짜 (2026-10-24)
- 서비스 선택 화면에 **"응답 확인" 버튼**과 카드마다 "응답 확인 10/24: 응답함/응답 없음" 문구 추가. 버튼은 서비스마다 키 없이 `/models` 한 번만 익명으로 요청(기존 `catalog_check`)해 결과를 `~/.agent-workshop/catalog-status.json`에 시각과 함께 저장한다. **무료 한도는 이 확인으로 알 수 없고 기록하지 않는다**(문구에도 명시). 확인은 백그라운드로 돌고 동시에 한 번만 실행된다.
- **확인**: 단위 테스트 3개(저장·불러오기, 깨진 파일, 백그라운드 실행과 중복 요청 거부·가짜 확인 함수라 실제 네트워크 없음), 채팅 API 테스트 전체 통과, 내장 브라우저에서 버튼과 카드 문구(클라우드 18곳에 "아직 안 함", 로컬은 문구 없음) 확인. **확인하지 않음**: 버튼을 눌러 실제 서비스에 요청한 결과(실서비스 요청이라 시험하지 않음), 응답이 오래 걸리는 서비스가 있을 때의 화면.
